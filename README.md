# Forge

Forge is an AI-first developer workspace for turning meetings, ideas, bugs, and daily work into focused execution.

## Stack

- React 19, Vite, and TypeScript
- Tailwind CSS and shadcn/ui-ready component conventions
- TanStack Router and TanStack Query
- Supabase client, React Hook Form, Zod, Framer Motion, and Lucide

## Local development

```bash
npm install
npm run dev
```

Run `npm run build` before committing. For local Supabase authentication and persistence setup, see `docs/DATABASE.md` and `docs/AUTH.md`.
